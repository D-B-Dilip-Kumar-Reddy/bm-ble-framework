# BM BLE Framework

A Python Bluetooth Low Energy (BLE) framework for automating and controlling Blackmagic cameras.

---

## 🚀 Features

- Connect to Blackmagic cameras via BLE
- Async-first design using `asyncio`
- Lightweight and extensible architecture
- Built for automation and integration workflows

---

## 📦 Installation

### Clone the repository

```bash
git clone https://github.com/D-B-Dilip-Kumar-Reddy/bm-ble-framework.git
cd bm-ble-framework
```

### Install runtime dependencies
```bash
pip install -r requirements.txt
```

### Install development dependencies
```bash
pip install -r requirements-dev.txt
```
